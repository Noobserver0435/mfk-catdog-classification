# МФК — классификация и сегментация кошек и собак

Учебное задание: обучить алгоритм, который **распознаёт** (классифицирует) и
**выделяет** (сегментирует) кошек и собак на изображениях.

Датасет: Kaggle «Dogs vs Cats» — 12 500 кошек + 12 500 собак, файлы вида
`cat.*.jpg` и `dog.*.jpg` (изображения без масок).

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `train.py` | Обучение небольшой свёрточной нейросети (CNN) для классификации |
| `segment.py` | Сегментация (выделение животного) предобученной моделью DeepLabV3 |
| `results/` | Результаты: графики, матрица ошибок, веса модели, примеры сегментации |

## Установка

Требуется Python 3.12 и библиотеки:

```bash
pip install torch torchvision numpy pillow scikit-learn matplotlib
```

## Запуск

```bash
# 1) Классификация (обучение + оценка + графики)
python train.py

# 2) Сегментация (выделение и подпись животного)
python segment.py
```

## Метод

### Классификация
Небольшая CNN (4 свёрточных блока + 2 полносвязных слоя, ~2,3 млн параметров).

- Обучение: 6000 изображений (3000 котов + 3000 собак), 15 эпох.
- Оптимизатор: Adam + понижение скорости обучения (StepLR) + weight decay.
- Аугментация: случайное отражение по горизонтали и поворот ±10°.
- Тест: 1000 изображений (500 + 500).
- **Итоговая точность: 88,6 %.**

### Сегментация
В датасете нет масок, поэтому обучить сегментационную модель «с нуля» невозможно.
Вместо этого используется предобученная модель **DeepLabV3** (на наборе Pascal VOC),
которая сама умеет выделять классы `cat` / `dog`. Модель строит пиксельную маску
животного, накладывает её полупрозрачным цветом и подписывает (cat / dog).

## Результаты (в `results/`)

- `training_curves.png` — кривые обучения (loss и accuracy по эпохам).
- `confusion_matrix.png` — матрица ошибок на тестовой выборке.
- `sample_predictions.png` — примеры предсказаний классификатора.
- `segmentation/*.png` — сравнение «оригинал | сегментация» (10 примеров).
- `catdog_cnn.pth` — обученные веса CNN.

## Примечание

Обучение выполнялось на CPU (графический ускоритель не использовался) и занимает
несколько минут, поэтому результат можно повторить на обычном компьютере.
